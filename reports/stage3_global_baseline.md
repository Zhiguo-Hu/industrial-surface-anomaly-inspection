# 冻结 ResNet18 全局特征基线

日期：2026-11-19（北京时间）

## 方法与数据

使用官方 ImageNet 预训练 ResNet18，冻结全部参数，移除分类层，保持评估模式。完整图片缩放至 256×256，不中心裁剪；采用 ImageNet 均值和标准差归一化。提取 512 维全局池化特征，再 L2 单位化。

正常特征库仅包含固定划分中的 167 张训练图，形状 `[167, 512]`。异常分数为单位化特征到正常特征库的最近邻欧氏距离。它不是概率，也没有“百分之多少异常”的含义。

42 张正常验证图的分数用于确定阈值：第 95 百分位、线性插值，阈值约 0.1310634；分数严格大于阈值才判异常。特征库与阈值先保存，再读取官方测试集特征。测试集未用于调整阈值、网络或预处理。

## 首轮结果

| 项目 | 结果 |
|---|---:|
| 测试图片 | 83 |
| 图像级 AUROC | 0.992857 |
| 缺陷召回率 | 100%（63/63） |
| 正常图片误报率 | 10%（2/20） |
| 准确率 | 97.59%（81/83） |
| 真正常 TN | 18 |
| 误报 FP | 2 |
| 漏检 FN | 0 |
| 真异常 TP | 63 |
| 验证集误报率 | 7.14%（3/42） |

三个缺陷类型的检出数分别为 broken_large 20/20、broken_small 22/22、contamination 21/21。误报为官方测试正常图 `good/006.png` 和 `good/010.png`，分数约为 0.1534 和 0.1340。

AUROC 衡量分数排序能力，与单个阈值下的误报率不同。第 95 百分位阈值在仅有 42 张验证图时，实际超过阈值的样本比例为 3/42，并非严格 5%。20 张正常测试样本也较少，单张误报就占 5 个百分点。

## 资源与验证

在 RTX 5060 Laptop GPU 上以 batch size=8、FP32 运行。训练、验证、测试特征提取总耗时分别约 2.88、0.64、1.28 秒，包括图片读取、预处理和冷启动，不作为正式延迟基准。PyTorch 峰值分配显存约 118.74 MiB，不包含驱动和其他应用占用。特征库文件约 344.46 KiB。

## 局限与下一步

这是单类别、固定划分的初始基线，不代表真实生产现场性能，也不是完整数据集的标准比较结果。训练阶段未更新模型权重；“建立特征库”不同于梯度训练。

全局池化丢失空间信息，目前不能定位缺陷。本轮不输出热力图、像素级 AUROC。首轮已检出全部测试异常，不以反复调整测试集结果为目标继续调参。

下一步：实现局部特征与 PatchCore 定位，沿用同一份数据清单，并另行确定适合正常验证数据的图像评分和阈值。当前已查看过测试结果，后续比较应如实作为探索性实验记录；若要做独立泛化评估，需要另留未参与开发的数据。
