# Data, pretrained weights, and method attribution

Datasets and pretrained weights are not distributed in this repository. Download them from their original publishers and follow their respective terms.

- MVTec AD: https://www.mvtec.com/research-teaching/datasets/mvtec-ad — CC BY-NC-SA 4.0. Used for the bottle pipeline validation. Cite the MVTec AD papers when reporting dataset results.
- Severstal Steel Defect Detection: https://www.kaggle.com/c/severstal-steel-defect-detection — access and use are subject to the competition terms. This repository contains generated split identities and file hashes, not original images or pixel annotations.
- TorchVision ResNet18 IMAGENET1K_V1: https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html — obtain pretrained weights separately from the official PyTorch download host.
- PatchCore: Roth et al., Towards Total Recall in Industrial Anomaly Detection, CVPR 2022. https://arxiv.org/abs/2106.08265 ; authors' implementation: https://github.com/amazon-science/patchcore-inspection . The local implementation is a simplified educational implementation, with deviations documented in reports/stage4_patchcore_lite.md.

The image generated by assets/create_sample.py is a synthetic pipeline fixture, not an industrial benchmark sample. No license choice for this project's own source code has been made yet.
